# Brand

Duas versões da mesma marca, copiadas do arquivo original `gutoexplorer.svg` sem redesenho. O retrato, o cabelo cacheado e o anel orbital são o motivo gráfico do sistema — trate-os como parte do logotipo, não como ilustração.

- **`guto-logo.svg`** — arte completa sobre fundo navy em gradiente (`#10295a` → `#061a3e`), proporção 1:1. Use como ícone de app, favicon, avatar e imagem social. O fundo é parte da peça.
- **`guto-mark.svg`** — a mesma arte sem o fundo, com transparência. Use sobre `sky-top`, `surface` e `void` (o herói do site e o cabeçalho usam esta versão).

A tinta da marca é `celeste` com `celeste-strong` na luz; o anel orbital é o mesmo traço. Não recolora para `accent` (o azul de ação), não gire, não recorte e não aplique sombra projetada. Em fundo claro, use a versão com fundo navy.

Tamanho mínimo: 28px de lado para o ícone quadrado e 32px para a marca transparente; abaixo disso o anel desaparece. Margem de respiro: no mínimo `space-3` (6px) em volta.
